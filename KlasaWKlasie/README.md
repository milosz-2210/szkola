Program do obsługi klasy
Prosty program w C++, który umożliwia wczytanie danych klasy oraz uczniów z klawiatury lub z pliku tekstowego.

Program wykorzystuje dwie klasy:

Osoba – przechowuje imię, nazwisko oraz numer ucznia.

Klasa – przechowuje nazwę klasy, wychowawcę oraz listę uczniów.

Po wczytaniu danych program wyświetla informacje o klasie i wszystkich uczniach.
