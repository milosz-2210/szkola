Skrzyżowanie

Prosty program Arduino symulujący działanie skrzyżowania z czterema kierunkami ruchu. Światła zmieniają się automatycznie w ustalonej kolejności, a pomiędzy każdym zielonym światłem występuje 2-sekundowa faza, w której wszystkie światła są czerwone.

Program wykorzystuje millis() do odmierzania czasu bez używania delay().
