Binarne drzewo - klasa

Program przedstawia implementację binarnego drzewa wyszukiwania (BST) w języku C++.

Program umożliwia:

dodawanie elementów rekurencyjnie,

wypisywanie elementów w kolejności rosnącej,

automatyczne usuwanie drzewa z pamięci za pomocą destruktora.

W projekcie wykorzystano klasę Drzewo, konstruktor, destruktor oraz dynamiczne przydzielanie pamięci.
