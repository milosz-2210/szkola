Sortowanie liczb
Program napisany w języku C++, wykorzystujący jednokierunkową listę połączoną do przechowywania liczb.

Program umożliwia:

wczytanie liczb z pliku a.txt,

wyświetlenie zapisanych danych,

posortowanie liczb rosnąco metodą sortowania bąbelkowego,

zapisanie posortowanych danych do pliku b.txt,

obsługę programu za pomocą prostego menu tekstowego.

Projekt pokazuje podstawy obsługi dynamicznej pamięci, wskaźników, list jednokierunkowych oraz operacji na plikach w C++.
